# تحديثات إضافية — دليل التنفيذ

هذا الملف يغطي **بس التحديثات الجديدة** من هذا التحديث. للإعداد الأول الكامل، ارجعي لـ `docs/SETUP.md`.

---

## 1) تنفيذي ملف SQL الجديد

في Supabase → SQL Editor → New query، الصقي محتوى `sql/migration-2-feedback.sql` كامل واضغطي Run.

هذا يضيف:
- عمود تقييم العميل (1-5) وملاحظاته بعد الاجتماع في جدول الحجوزات
- دالتين جديدتين (`submit_feedback`, `get_booking_for_feedback`) يستخدمهم ملف `feedback.html`
- نسخة محدّثة من `bookings_export` تتضمن التقييم والملاحظات

## 2) انشري دالة البريد الجديدة

من نفس الطرفية (PowerShell) اللي استخدمتيها قبل:
```bash
supabase functions deploy send-feedback-request
```

## 3) جدولي إرسالها تلقائيًا

في SQL Editor، نفذي (استبدلي الرابط لو تغيّر مشروعك):
```sql
select cron.schedule(
  'send-feedback-every-15-min',
  '*/15 * * * *',
  $$
  select net.http_post(
    url := 'https://pvaexipdewgwowhhbmmo.supabase.co/functions/v1/send-feedback-request',
    headers := '{"Content-Type": "application/json"}'::jsonb
  );
  $$
);
```

## 4) ارفعي كل الملفات المحدّثة على GitHub

هذي المرة، **احذفي المستودع بالكامل وأنشئي وحد جديد بنفس الاسم**، وارفعي فولدر `leewan-booking` كامل من جديد (ما عدا مجلد `supabase/`). هذا يضمن عدم بقاء أي ملف قديم متضارب مع التحديثات — وهذا بالضبط سبب أغلب الأعطال اللي واجهناها بالجولة اللي فاتت.

بعد الرفع، اربطي المستودع الجديد بـ Cloudflare Pages بنفس خطوات أول مرة.

## ملخص الإصلاحات وأسبابها الحقيقية

| # | المشكلة | السبب الحقيقي | الحل |
|---|---|---|---|
| 1 | تكرار "ليوان أرُب" بالفوتر | نص ثابت بالعربي داخل HTML بدل ترجمة كاملة | دمجت النص بترجمة واحدة لكل لغة |
| 2 | زر EN ما يشتغل + اختفاء اللون البني | كود يشير لعنصر `#year` تم حذفه، يكسر كل الجافاسكربت بالصفحة | حذفت الإشارة الميتة بكل الملفات |
| 3 | محاذاة اسم القاعة | نفس سبب #2 (كانت اللغة ما تتبدل أصلًا) | انحلت تلقائيًا |
| 6 | الوقت يطلع مختلف بالإيميل | الكود كان يفسّر الوقت حسب توقيت جهاز الزائر/السيرفر، مو توقيت الرياض الثابت | ثبّت التوقيت على `Asia/Riyadh` (+03:00) بكل مكان: الحجز، العرض، لوحة التحكم، والإيميل |
| 7 | ضيف ما يستلم إيميل | الأرجح: الضغط Enter بدل زر "إضافة" ما كان يضيف الضيف فعليًا | فعّلت زر Enter، وتأكدي دايمًا تشوفين "شريحة" البريد تظهر تحت الحقل قبل تأكيد الحجز |

**ملاحظة مهمة لبند 7:** لو صار عندك حجز فيه ضيف وشريحة بريده ظاهرة بوضوح، ولسا ما وصله إيميل — افتحي حساب Resend → **Logs**، وشوفي هل فيه محاولة إرسال لبريد الضيف أصلًا (نجحت أو فشلت). لو ما فيه محاولة إطلاقًا، ارجعيلي بصورة من صفحة Logs وبنكمل التشخيص.
